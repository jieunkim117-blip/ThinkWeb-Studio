# 🚀 ThinkWeb Studio: Architect Edition

**ThinkWeb Studio**는 웹 인터페이스를 시각적으로 설계하고 정밀한 레이아웃을 구성할 수 있는 고성능 UI 엔진입니다. 단순한 편집기를 넘어, 개발자가 구상하는 디자인을 즉각적으로 HTML 표준 코드로 변환해 주는 강력한 아키텍트 도구입니다.

## ✨ Key Features

* **Precision Layout Engine**: 픽셀 단위의 정밀한 개체 이동 및 배치 시스템.
* **Cross-Platform Optimization**: 모든 디바이스 환경에서 끊김 없는 조작을 지원하는 유연한 인터페이스.
* **Real-time Source Generation**: 편집과 동시에 웹 표준 소스 코드를 생성하는 라이브 싱크 엔진.
* **Minimalist Developer UI**: 블랙 & 라임 테마의 직관적인 대시보드와 인스펙터 패널.
* **Massive Restoration System**: 사용자의 몰입감을 극대화하는 독보적인 아키텍처 UX.

## 🛠 Tech Stack

* **Core**: HTML5, CSS3, JavaScript (Modern ES6+)
* **Typography**: Pretendard, Black Han Sans, JetBrains Mono
* **Icons**: Font Awesome 6.5.1 Professional
* **Architecture**: Responsive Layout & Scale Compensation Logic

## 📖 How to Use

1.  **Add Objects**: 상단 리본 메뉴의 '삽입' 탭을 통해 텍스트나 기하학적 요소를 캔버스에 배치합니다.
2.  **Object Manipulation**: 마우스나 터치를 이용하여 개체를 자유롭게 조작합니다. 시스템은 실시간으로 좌표를 계산합니다.
3.  **Property Tuning**: 인스펙터 패널을 통해 폰트 크기, 컬러, 스타일 등의 속성을 정밀하게 제어합니다.
4.  **Export Code**: 최적화된 결과물을 클립보드에 복사하여 실제 프로젝트에 즉시 적용합니다.
